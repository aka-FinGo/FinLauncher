## ✨ Asosiy Imkoniyatlar (Key Features)

* 🌊 **Ergonomik Alifbo To'lqini (Alphabet Wave Slider):** 
  * Ekranning o'ng tomonida A–Z vertikal alifbosi.
  * Barmog'ingizni yuqoridan pastga yurgizganingizda to'lqinsimon (wave animation) harakat va har bir harfda aniq haptik tebranish (vibratsiya).
  * Katta ekranli telefonlarda ham birgina bosh barmoq bilan barcha ilovalarga soniyalar ichida kirish.
* ⭐️ **Bosh Ekran Sevimlilari (Home Favorites):**
  * Ekranni ortiqcha tartibsizliklardan tozalab, faqat eng ko'p ishlatiladigan 5–8 ta sevimli ilovani saqlash.
* 🕒 **Minimalist Soat, Sana va Batareya Vidjeti:**
  * Toza AMOLED qora fon va zamonaviy tipografiya.
* 💬 **Inline Bildirishnomalar:**
  * Xabarlarni ilovani ochmasdan bosh ekranning o'zida ko'rish imkoniyati.
* 🔒 **Maxfiylik va Ilovalarni Yashirish (Hide Apps):**
  * Istalgan maxfiy yoki kam ishlatiladigan ilovalarni ro'yxatdan yashirish.
* ⚡️ **Yengil va Resurs Tejamkor:**
  * RAM xotirasini deyarli band qilmaydi (~25–35 MB), batareyani ortiqcha yemaydi.

---

## 🛠️ Texnologiyalar (Tech Stack)

* **Til:** Kotlin 1.9.x
* **UI Framework:** Jetpack Compose & Material 3 (Material You)
* **Arxitektura:** Clean Architecture + Repository Pattern
* **Saqlash:** Jetpack DataStore Preferences
* **CI/CD:** GitHub Actions (Avtomatik Release APK yig'ish va imzolash)
